Start anything on AROS
from the keyboard.

Launcher waits in the background. CtrlAltSpace opens its panel, a few letters find the program and Return starts it. The same panel does sums, converts units and currencies, finds files and open windows, installs packages and remembers what you copied.

For ABIv11 distributions, mainline AROS on PC and the Raspberry Pi. Version 0.7.1.

Pick something to type

Programs, windows and files in one list.

Letters may be scattered: wc finds WordCraft. Case and accents do not matter, and programs you start often move up the list.

Open windows are listed by title beside the programs, and Return brings the chosen one to the front.

Files and drawers come from folders you pick in the settings. No folder is searched until you add one. You can leave drawers out, or names by pattern, for example #?.bak. The index is built in the background and kept between starts.

It answers before you press Return.

Type a calculation or a question in words and the answer is the first result. Return copies it to the clipboard.

  • sqrt(2)1.41421356237
  • 0x1f+132
  • 10 km to mi6.21371 mi
  • 72 f in c22.2222 °C
  • 20% off 8064
  • 15:30 warsaw to new york09:30 New York
  • 100 usd to plnthe day's rate
  • weather warsawtemperature and sky

Rates are fetched over HTTPS at most twice a day and kept for when there is no network. The request is for one public file, so nothing about you or what you typed leaves the computer. A weather question sends the city name to Open-Meteo and nothing else.

Tab shows what else you can do.

Press Tab on a result for its other actions: show it in its drawer, copy its path, open a Shell there.

Two of the actions give a program a shortcut of its own. An alias is a short word; typed whole, it puts that program first. A hotkey starts the program from anywhere without opening the panel. You write it the way commodities do: ctrl alt w, lalt f5, ramiga t.

"Aliases and Hotkeys" lists everything you have set, and Return on a line changes or removes it.

Clipboard history

Type clip for the last 50 texts you copied; more letters narrow the list. Return puts one back on the clipboard, Tab deletes an entry or all of them. The history is kept in memory only. Nothing is written to a disk, so a password you copied is gone when the launcher quits.

Packages from apkg

With apkg installed, packages from its catalogue that you do not have yet are found by name or by a word of their description. Return asks once. A second Return installs the package in a console window.

Shell commands and the system

Start the line with > and the rest runs as a Shell command in a console of its own. "Restart Computer" and "Shut Down Computer" are found like programs and ask for a second Return before they act.

Widgets it shares with Dockbar.

Currency answers and the weather come from widgets, small packages in the format Dockbar uses for its tiles and cards.

A widget is a drawer with a manifest, a description of its settings, a views file and a provider program. The provider fetches the data and writes a snapshot of named fields and rows. Each host shows that snapshot its own way: Dockbar draws a tile and a card, the launcher puts the same numbers into an answer.

The card is described by the widget. views.json lists blocks such as text, trend, icon, row and list, and Dockbar lays them out. A new widget does not need a new version of the host.

"expanded": [
  { "text": "heading" },
  { "text": "basis", "style": "muted" },
  { "spacer": 10 },
  { "list": "top", "max": 5, "row": [
    { "text": "label" },
    { "trend": "plot", "text": "detail", "align": "right" },
    { "text": "value", "align": "right" }
  ] }
]

Currency comes with both programs. Weather comes with Dockbar, and the launcher uses it when Dockbar is installed. For now the launcher reads these two widgets; reading any installed widget is planned. You can write a widget for Dockbar today: the format is documented.

Colour themes from Limpet.

The panel reads themes in the format of Limpet, the AROS terminal, so the launcher and your Shell can wear the same colours.

You do not need Limpet

Fifteen of Limpet's themes come in the launcher's Themes drawer. If Limpet is installed, the themes in its own drawer are found by name as well. A theme file of your own works too.

Dark and light from one theme

A theme is either dark or light. Choose the other variant and the launcher makes it: every colour keeps its hue and takes the mirrored lightness, and the text is moved until it reads clearly.

The same look as Dockbar

Without a theme, the launcher uses the dark and light colours Dockbar has, so the two look alike on one desktop. Compact rows and the frosted glass behind the panel are switches in the settings.

ARexx, both ways.

The launcher has a public port, LAUNCHER, with the commands SHOW, HIDE, TOGGLE, RESCAN, VERSION, QUIT and HELP. A script can open the panel with a query already typed:

address LAUNCHER 'SHOW calc'

It also sends. Type rx and a space, choose one of the public ports, then type the command. Return sends it and the answer appears under the row.

rx LAUNCHER VERSION

Systems

ABIv11 distributions on x86_64, mainline AROS x86_64 (ABIv1, a nightly from 2026-11-06 or later) and the Raspberry Pi (AArch64, ABIv1). Each gets its own archive; the binaries do not cross.

What it needs

TrueType fonts in FONTS:TrueType (DejaVu Sans, as installed with the system). Currency and weather need the network. Packages need apkg.

Starting it

Double-click Launcher. Nothing appears; it waits for CtrlAltSpace. The first start from its icon also sets it up to start with the system, which you can switch off in its settings. The hotkey is the CX_POPKEY ToolType of the icon.
